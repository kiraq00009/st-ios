# Studio — لوحة تحكّم مشاريعي (آيفون)

تطبيق آيفون أصليّ (SwiftUI) للمالك فقط: أوّل شاشة «مشاريعي»، وكلّ مشروع إله لوحته. أوّل مشروع: **دورلي**.

- الدخول بكلمة سرّ المدير — تنحفظ بخزنة الآيفون (Keychain)، وما بالتطبيق أيّ سرّ.
- دورلي: أرقام حيّة، خطوط المزوّدين، محادثات الدعم (قراءة + ردّ + مسح)، طلبات المستخدمين (وفّرته / ردّ / مسح)، يُشاهَد الآن، مساعد دورلي، الملاحظات، الأكثر مشاهدة.
- البناء: GitHub Actions (نفس دورلي) ⇒ `Studio-unsigned.ipa` ⇒ Sideloadly.
